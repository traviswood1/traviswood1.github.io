3D homepage demos

Scroll-driven Three.js homepages for three made-up businesses. Each one is a single HTML file with no build step, and every model is built in code, so there are no 3D files to download.

  • Halden H1 turntable

    Product reveal. The lid lifts, the tonearm drops onto the record, then the parts separate with labels.

  • Tamarack Hollow cabin

    Vacation rental. Afternoon turns to sunset and night as you scroll, then the roof opens to show the rooms. Includes a working date checker.

  • Bluffline Outfitters

    Canoe outfitter. A topographic map with the camera floating the river route stop by stop, next to the trip itinerary.
