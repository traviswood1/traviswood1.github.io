Hex Clash

A 3D hex-tile tactics game that runs in the browser. Roll a random battlefield, draft start corners and units, then fight using height, terrain and unit abilities, against a friend or a computer opponent. Built with JavaScript and Three.js.

Battle Chess

Chess where the pieces fight. Each unit has its own stats and abilities, and the board is a torch-lit dungeon with animated 3D models and spell effects. The computer opponent searches ahead, and I balanced the units by having it play itself hundreds of times. Built with Three.js.

In development

Infinite Quest

An action RPG roguelite that feels like an early-2000s console dungeon crawler. Every floor is generated from a seed, with new map layouts and new monster species in themed zones, plus loot, spells and risk pacts that make a run permadeath. Built in Godot 4 with C#, headed for Steam.
